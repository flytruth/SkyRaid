# SkyRaid by BexindStudio

Плагин для **Paper 1.21.11**: небесные базы с защитой ядра на топливе и системой рейдов.

Собран под Java 21. Работает на актуальных сборках
Paper ветки 1.21.1; при необходимости целевая версия меняется одной строкой в `pom.xml`.

---

## Механика

### Покупка и остров
- `/base buy` — игрок платит ресурсами из конфига (`base.buy-cost`), остров появляется
  на случайных координатах на высоте `island.spawn-height` — случайно наткнуться на чужую
  базу нельзя, телепорты на чужой остров (жемчуг, хорус) блокируются.
- Остров защищён регионом: строить может только владелец.
- Улучшение острова (`/base upgrade` или меню ядра) расширяет платформу:
  9×9 → 13×13 → 17×17 → 21×21 → 25×25. Достраиваются только воздушные блоки,
  постройки владельца не затираются.

### Ядро базы
- В центре острова стоит ядро — **Heavy Core** (визуально — навершие булавы).
- ПКМ по ядру открывает меню: запись защиты топливом, улучшение стены, расширение острова.
- **Запись ядра:** топливо из инвентаря (по умолчанию огненный порошок) конвертируется
  в защиту: 1 шт = 1 час, максимум 24 часа. Пока защита активна — базу нельзя рейдить.

### Стена хранилища
- За ядром стоит хранилище (сундук), опечатанное стеной 2×2.
- Уровни стены: **железная (8 HP) → алмазная (16 HP) → незеритовая (32 HP)**.
  Улучшение — в меню ядра, цена в `wall.upgrade-cost`.

### Рейд
- `/raid` — GUI со списком баз, у которых истекла защита: ник владельца (голова),
  уровень стены и острова. Координаты в меню не показываются.
- После подтверждения рейдер телепортируется к острову, запускается таймер **10 минут**
  (боссбар), владельцу приходит оповещение.
- Стена ломается только взрывчаткой: ПКМ по стене с **TNT (динамит, 4 урона)** или
  **огненным зарядом (1 урон)**; предмет расходуется, есть кулдаун между применениями.
- После разрушения стены рейдер открывает хранилище. Опустошил сундук — рейд успешен.
- Рейд завершается: таймер / смерть / выход с сервера / уход от острова / `/raid leave`.
  После любого исхода рейдера телепортирует на спавн, стена восстанавливается.
- На время рейда включайте PvP своими средствами: плагин не трогает PvP-правила,
  а публикует события (см. ниже).

## Команды и права

| Команда        | Описание                      | Право               |
|----------------|-------------------------------|---------------------|
| `/base buy`    | Купить базу                   | `skyraid.command.base` (по умолчанию всем) |
| `/base tp`     | Телепорт на базу              | `skyraid.command.base` |
| `/base upgrade`| Расширить остров              | `skyraid.command.base` |
| `/base info`   | Информация о базе             | `skyraid.command.base` |
| `/base reload` | Перезагрузка конфига          | `skyraid.admin` (op) |
| `/raid`        | Меню рейдов                   | `skyraid.command.raid` (по умолчанию всем) |
| `/raid leave`  | Покинуть рейд                 | `skyraid.command.raid` |
